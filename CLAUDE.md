# Clawd: notes for Claude

Clawd is a pixel-art desktop pet for Windows: a little orange guy who lives on the desktop. The whole app is one PowerShell script, `clawd.ps1`, running Windows Forms, plus a few C# helpers compiled with `Add-Type`. Public repo: https://github.com/finnvangronsveld/clawd

**Keep this file and `README.md` up to date whenever behaviour changes.** The owner asked for this explicitly.

## Layout

| Path | What |
|---|---|
| `clawd.ps1` | The entire pet. `-RenderFrames <dir>` renders the scripted README demo off-screen instead of running. |
| `clawd.ico` | Icon. It's generated by `Make-Icon` in `clawd.ps1` if missing, but it's committed too. |
| `Install Clawd.cmd` / `Uninstall Clawd.cmd` | Double-click wrappers (CRLF line endings, see `.gitattributes`). |
| `tools/install.ps1`, `tools/uninstall.ps1` | Per-user install to `%LOCALAPPDATA%\Programs\Clawd`: Start menu + Startup shortcuts and a Settings › Apps entry. Their params (`-Dest -MenuDir -StartupDir -RegName -Quiet`) exist only for sandboxed testing. |
| `tools/make_gif.py` | Frames → `docs/clawd.gif` (Pillow; magenta = transparent). |
| `docs/clawd.gif` | The README demo. |
| `launch.vbs`, `clawd.log` | Generated per machine, gitignored. `launch.vbs` starts the script with no console window. |

The owner's dev copy runs from this folder. Its Start-menu and Startup shortcuts point here, because `clawd.ps1` repoints them at its own location on every start.

## Runtime and gotchas (read before editing)

- **Target Windows PowerShell 5.1** (`powershell.exe -STA`), not pwsh. Keep `.ps1` files **ASCII only**: 5.1 reads BOM-less UTF-8 as ANSI.
- **Variable names are case-insensitive.** `$G` and `$g` are the same variable. This bit us once: gravity is `$GRAV` and the canvas Graphics object is `$g`. `$S` (pixel scale) must never be shadowed, so event handlers use `param($sender, $e)`, not `$s`.
- **Don't name functions after built-in aliases.** `R` is `Invoke-History`, which is why the draw helper is `Px`.
- PowerShell uses dynamic scoping: a local `$ox` in `Render-Frame` is what nested calls see as `$OX`. This is harmless today, but be aware of it.
- **Transparency is a colour key (magenta 255,0,255).** Never anti-alias anything on a layered window, because it bleeds pink fringes. Text uses `SingleBitPerPixelGridFit`. Rotation goes through `[ClawdSprite]` (nearest neighbour, LockBits), never through GDI+ transforms.
- **Overlay windows** (bullets, web line): create the form, call `[ClawdNative]::MakeOverlay` (tool window + click-through + no-activate), then show and hide with `ShowNoActivate` / `HideWin`. **Never call `.Show()` on them**, because it steals focus from the user's app.
- Every window is hidden from the taskbar and Alt+Tab (`HideFromAltTab`, re-applied periodically).
- **DPI:** the process calls `SetProcessDPIAware`. `$S` (screen px per sprite pixel) comes from DPI, and `$k = $S/3` scales speeds and gravity. Use `$k` for anything in screen pixels.
- Single instance: mutex `Local\ClawdDesktopPet`. A second launch signals the `Local\ClawdPoke` event, and the running Clawd waves ("I'm right here!").

## How the script is organised (top to bottom)

1. Params, mutex and poke event, `Write-Log`.
2. C# helpers via `Add-Type`:
   - `ClawdNative`: idle time, key-press counting (counts only), window rects/visibility, `FindTop`, `FindClimbTarget`, foreground title, overlay helpers.
   - `ClawdCloud`: the thought-cloud bitmap.
   - `ClawdSprite`: pixel-grid rotation, `DrawRotated` and `RotateCells`.
3. Media sessions (WinRT GSMTC) and `Get-MediaStatus`: `playing` / `paused` / `none`. Spotify is ignored.
4. Canvas and palette:
   - The canvas is `$GW` × `$GH` sprite pixels ("cells"), with Clawd's top-left at `$OX`, `$OY`; he is 22×16 cells.
   - Brushes `$b*`, glyphs, line lists (comments, complaints, think words), `$videoRx`.
5. Shortcuts and icon.
6. The window and state:
   - The state lives in one hashtable, `$st`. Add new fields to its initialiser.
   - Helpers: `Set-Mode`, `Say`, `Start-Hop`, `Get-Ground` (handles window platforms), `Pick-Activity`, `Try-Climb`, and the aiming helpers (`Get-Aim`, `Aim-At`, `Get-Muzzle`, `Fire-Gun`).
7. Drawing:
   - `Render-Frame` is the front view. Order: silhouette → shading → suit → face → props → gun → rotation → particles → bubble.
   - `Render-Back` is the movie-night back view. `Step-Watch`, `Get-Comment`.
8. Thought-cloud menu: `$menuItems`; every behaviour should have an entry.
9. Bullets, the web overlay (`Web-Begin` / `Web-Draw` / `Web-End`, `New-Anchor`), `Poof`. Then mouse handlers.
10. The tick (every 30 ms):
    - Reset the per-frame visuals.
    - Sensors: cursor, idle, keys, foreground video, media state.
    - Triggers: video → sleep → pet → wave → typing → climb.
    - `switch ($st.mode)`, then the screen clamp and position, `Update-Particles`, `Render-Frame`.
11. `Step-Smash`, `Update-Particles`, `Invoke-Demo` (the scripted GIF).

### Modes

- **Free modes** (can be interrupted by triggers): `walk`, `idle`, `chase`.
- **Everything else:**
  - `fall` (also hops and jumps; lands on window tops), `crouch`, `goclimb`
  - `wave`, `pet`, `dizzy`, `dance`, `coffee`, `think`, `typing`
  - `yawn`, `sleep`
  - `smash`, `gun`, `trick`
  - `gowatch`, `watch`, `paused`
  - `suitup`, `swing`, `heropose`
- Visual fields such as `arms`, `eyeStyle`, `mouth`, `laptop`, `gun`, `back`, `rot` and `sit` are **reset every tick**. Modes set them each frame. Persistent flags (like `suit`) are not reset.

**Adding a behaviour:**
1. Add a `case` in the tick switch.
2. Add an entry to `Pick-Activity` if it should happen on its own.
3. Add a menu item.
4. Optionally add a segment to `Invoke-Demo`.
5. Update the README tables and this file.

## Testing (no unit tests: run it and look)

- **Parse check:** `[System.Management.Automation.Language.Parser]::ParseFile(...)`.
- **Behaviour tests:**
  - Copy `clawd.ps1` to `t_<name>.ps1` (gitignored).
  - Rename the mutex, poke event and log strings in the copy so it runs next to the real one.
  - Skip the shortcut setup.
  - Inject triggers, e.g. `Set-Mode 'swing'` at a tick, or a faked `$videoOn` / media status.
  - Optionally log `Set-Mode` calls.
  - Run it hidden, read `t_<name>.log`, then delete the copy.
- **Visuals:** run `-RenderFrames` and build contact sheets of the frames. For on-screen checks, take DPI-aware `CopyFromScreen` screenshots. Test copies take about 5 s to start, because of `Add-Type` compiles.
- **Installer:** run `tools/install.ps1` / `tools/uninstall.ps1` with the test params into a temp folder, never into the real Start menu.

## Release checklist

1. Re-render the GIF:
   ```
   powershell -STA -File clawd.ps1 -RenderFrames <tmp>
   python tools/make_gif.py <tmp> docs/clawd.gif
   ```
2. Update `README.md` and this file.
3. Commit, ending the message with the Co-Authored-By line, and push `main`.
4. Build `dist/Clawd.zip`, which holds `clawd.ps1`, `clawd.ico`, `README.md`, both `.cmd` files and `tools/install.ps1` + `tools/uninstall.ps1`.
5. Run `"C:\Program Files\GitHub CLI\gh.exe" release create vX.Y dist/Clawd.zip ...`. The README links `releases/latest/download/Clawd.zip`.
6. Restart the owner's running Clawd: stop the `powershell.exe` whose command line contains `PROJECTS\Clawd\clawd.ps1`, then start `launch.vbs`.

## Product rules

- **Privacy:**
  - Keyboard: count key presses only, never which keys.
  - Window titles and media state are read locally only.
  - Nothing is stored or sent anywhere.
  - Keep the README privacy section accurate.
- **Public-facing text** (README, menu, releases): don't use trademarked character names. The spider costume is the "web-slinger suit".
- **Look:**
  - Chunky pixel art.
  - Dark-brown outline (`$bOutline`), a light top-left edge and a shaded bottom-right.
  - Clawd orange is `217,119,87`.
